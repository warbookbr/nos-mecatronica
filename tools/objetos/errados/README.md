# Arquivos errados dos requisitos e do caderno

Cada arquivo aqui é o exemplo certo de [`../exemplos/objeto-de-teste/`](../exemplos/objeto-de-teste/) com uma só mudança que quebra uma regra, e ao lado dele está a recusa que `npm run objetos:conferir -- <arquivo>` tem de imprimir, byte a byte. O `npm run objetos:conferir` sem argumento confere todos eles, e o teste em [`../conferir.test.mjs`](../conferir.test.mjs) também. A recusa diz o tipo e a versão do arquivo, o caminho JSON do campo, a regra e o valor recebido.

[`campo-ausente.requisitos.json`](campo-ausente.requisitos.json) tira o `orcamento`, que é obrigatório. [`valor-sem-origem.requisitos.json`](valor-sem-origem.requisitos.json) tira a origem da massa na ponta. [`obrigatorio-ausente.requisitos.json`](obrigatorio-ausente.requisitos.json) escreve o `alcance`, obrigatório com valor, como ausente com motivo. [`aprovacao-sem-frase.caderno.json`](aprovacao-sem-frase.caderno.json) tira a frase da pessoa da aprovação dos requisitos. [`aprovada-depois-de-aberta.caderno.json`](aprovada-depois-de-aberta.caderno.json) aprova a forma com a etapa de componentes ainda aberta. [`reaberta-sem-motivo.caderno.json`](reaberta-sem-motivo.caderno.json) reabre os requisitos sem dizer por quê.
