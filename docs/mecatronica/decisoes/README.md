# Decisões

As escolhas que continuam governando o trabalho, uma por arquivo, numeradas em ordem (`0001-assunto.md`). Cada registro diz o que ficou decidido, por quê, quando reabrir, a origem e o registro que ele substitui. Registro aceito não é editado: uma decisão nova o substitui, nomeando o antigo na linha "Substitui:", e o antigo passa a dizer "Estado: substituído por" o arquivo novo.

Também mora aqui a declaração de cada motor de simulação de terceiros que o repositório usar, com a versão, a licença e a forma de chamar, como pede o [contrato](../../../CLAUDE.md).
